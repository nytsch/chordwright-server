# Chordwright Data

Deine Chordwright-Bibliothek als Ordner mit `.chordpro`-Dateien unter `/share/chordwright`. Alle Geräte, die sich verbinden, sehen dieselben Songs; Änderungen von zwei Geräten werden zusammengeführt statt überschrieben. Auf der Bühne kann ein Gerät leiten und die anderen folgen mit (Set, Lied, Start, im Takt).

Anleitung: Reiter **Dokumentation**.
